# 쉬운 작업 설명

정책 원문: `.leerness/plain-language-reporting.md`. 보고마다 한 번만 적용하고, 정책 본문을 인수인계나 이 스킬에 다시 복제하지 않습니다.
프로젝트 전체 적용은 `leerness toggle set plain-language-reporting on`으로 켭니다. 한 번의 쉬운 설명 요청은 저장 설정 없이 처리합니다.
기존 테스트와 근거 검증 요구는 그대로 지킵니다.
