# 외부 프로젝트 연결 — O01–O10

상태: 구현 중. 기존 R01–R12(12/12)와 별도 분모이며 전체 제품/공수 진행률이 아니다.
사용자의 '다음 단계 개발' 지시에 따라 이전에 제안한 명시적 연결·선택적 계측·지원 범위 진단을 진행한다.
기존 UI를 재사용하며 새 화면 리디자인/자동 소스 수정/클라우드 연결은 하지 않는다.

| ID | 고정 인수 기준 | 상태 |
|---|---|---|
| O01 | CLI init 기본 미리보기, --write 신규 JSON만 생성, 기존 파일 덮어쓰기 금지 | 미검증 |
| O02 | 엄격한 설정 스키마, 상대 파일 allowlist, 루트 밖·숨김·symlink·과대 파일 거부 | 미검증 |
| O03 | doctor는 Vite config/스크립트/.env 실행·조회 없이 설치된 지원 버전·선택 파일·지원 callback 진단 | 미검증 |
| O04 | 로컬 Vite 연결, UI/agent 권한 분리·포트 충돌·중복 플러그인·종료 정리 | 미검증 |
| O05 | npm pack 설치용 공개 CLI/exports, 저장소 밖 독립 소비 프로젝트에서 실행 | 미검증 |
| O06 | 외부 React 브라우저 클릭→HTTP→OBSERVED→원본 코드, 비선택 파일은 소스 미확인 | 미검증 |
| O07 | 기존 업무 API/오류 의미 보존, 수집기 중단 후 앱 동작 및 호스트/출처 경계 | 미검증 |
| O08 | 외부 프로젝트 운영 build에서 계측/소스 manifest/개발 endpoint 제거, noop 동작 | 미검증 |
| O09 | 외부 프로젝트 HMR 과거 코드/새 코드 분리, 프로젝트 파일 무변경·기존 전체 회귀 | 미검증 |
| O10 | 사용자가 지정한 실제 업무 프로젝트 1개에서 연결·핵심 흐름 인수 검증 | 미실행: 대상 미지정 |

O01–O09의 독립 소비 프로젝트는 자동 생성한 검증용 프로젝트다. 사용자 업무 프로젝트 검증으로 계산하지 않는다.
지원 시작 범위: Node 22+, 설치된 Vite 7, React 19, 루프백 HTTP, base=/, 단일 Vite root, 명시적 inline callback.
Next/SSR/모노레포 자동 탐색/별도 Node 서버 자동 연결/모든 함수 자동 계측은 미지원.
프로젝트 설정 파일과 플러그인은 신뢰한 로컬 코드다. doctor/init는 실행하지 않고 dev는 --trust-project가 필요하다.
