Open View 사용 방법

화면은 제품 설계 프로토타입입니다. UI 시연과 실제 폴더 분석을 구분해서 사용하세요.

01 / 직접 조작

고객 페이지 노드 안의 입력칸과 저장 버튼을 사용할 수 있습니다. 외부 요청 없이 시뮬레이션 연결과 타임라인이 표시됩니다.

02 / 연결 확인

노드와 연결선을 클릭하면 파일 위치·함수·예시 요청을 봅니다. 노드 헤더를 끌어 위치를 바꾸고 배경을 끌어 이동합니다.

03 / 폴더 분석

서버를 실행한 폴더의 TS/JS 파일을 읽어 실제 선언·호출·JSX 핸들러를 표시합니다. 이 모드는 런타임 추적이 아닙니다.

04 / 연결되지 않은 것

임의 프로젝트의 브라우저 SDK, OTel, DB 내부 추적, 호스팅 커넥터는 아직 구현되지 않았습니다. 상세 범위는 설계서를 확인하세요.
